# Elegant Eagles Project

Object-oriented Python platformer project with custom movement, collision, and enemy behaviour.

The full write-up is available in [`Elegant Eagles Project-1.pdf`](Elegant%20Eagles%20Project-1.pdf). The code listing begins from page 206 of the document.

## What It Shows

- Object-oriented game architecture.
- A* pathfinding for adversarial enemy movement.
- Custom physics and collision logic.
- Game-loop design, state management, and user interaction.
- Written explanation of implementation decisions and testing.

## Notes

This repository currently preserves the submitted project document rather than a standalone extracted source tree. A future cleanup pass should extract the code from the PDF into normal Python modules so the project can be run directly from GitHub.
